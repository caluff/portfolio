## Page visit counter

The profile visit counter uses Upstash Redis so its value persists across deployments.

1. Create an Upstash Redis database, directly or through the Vercel Marketplace.
2. Copy `.env.example` to `.env.local` for local development.
3. Set `KV_REST_API_URL` and `KV_REST_API_TOKEN` locally and in the Vercel project environment variables.
4. Redeploy the project after adding the production variables.

The counter records one visit per browser session and starts at zero when the Redis key is created.
